# Tarea 4 - Almacenamiento y Consultas en MongoDB (SECOP II)

Repositorio del componente práctico individual del curso **Big Data (202016911)** - UNAD.

- **Autor:** Carlos Guillermo Herrera Meza
- **Grupo:** 202016911_22
- **Motor:** MongoDB Community Server 9.0.8 + MongoDB Compass (`mongosh`)
- **Base de datos:** `secop2_bigdata` (150 documentos: 20 entidades, 30 contratistas, 100 contratos)

## Archivos incluidos
- `cargar_secop2.js`: Creación de colecciones y carga inicial de 150 documentos.
- `consultas_secop2.js`: Consultas CRUD, filtros, operadores (`$gte`, `$in`, `$regex`), joins (`$lookup`) y agregaciones estadísticas (`$group`, `$sum`, `$avg`, `$min`, `$max`).
